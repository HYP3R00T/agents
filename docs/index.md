# Agents

A growing collection of reusable skills and resources for coding agents. Skills are the starting point; other agent tools and workflows can live here as the collection grows.

## Available skills

| Skill                              | Description                                                                                         | Source                                                                         |
| ---------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [commit-now](skills/commit-now.md) | Group authorized changes into coherent Conventional Commits, with explicit control over file scope. | [Skill folder](https://github.com/HYP3R00T/agents/tree/main/skills/commit-now) |

## Using a skill

1. Open its guide and review what it does, when it runs, and what it can change.
2. Copy the complete skill folder into the skills location supported by your agent. Keep `SKILL.md` and any supporting files together.
3. Follow your agent's instructions for discovering skills, then invoke the skill as described in its guide.

Skill discovery and installation vary by agent. Review the instructions before granting a skill access to your repository.
